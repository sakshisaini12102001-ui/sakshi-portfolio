# Sakshi Saini — Portfolio

A Next.js portfolio site built from your CV: live-build showcase, stack, experience
timeline, and contact section. Fonts (Space Grotesk / Inter / JetBrains Mono) load from
Google Fonts at build time, so an internet connection is needed to build — this is normal
and will work automatically on Vercel.

## Run it locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Edit content

All text content (projects, stats, experience, contact info) lives in
`app/page.js` near the top of the file, in the `STATS`, `BUILDS`, `STACK`, and
`EXPERIENCE` arrays. Colors and fonts are in `app/globals.css`.
